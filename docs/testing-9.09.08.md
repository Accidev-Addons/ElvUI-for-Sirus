# Проверка 9.09.08

## Автоматические проверки

Из корня ElvUI-for-Sirus:

```bash
python -m pip install lupa
python -m unittest discover -s tests -p 'test_*.py'
```

Это запускает весь набор, включая тесты скинов, навигации рейда, локалей, версии и исправлений аудита. Отдельный запуск `test_sirus_regressions.py` не является полной проверкой.

Для интеграции плагина клонировать ElvUI_DmgAtNameplates рядом с ElvUI-for-Sirus; без него два интеграционных теста явно пропускаются. Самостоятельные тесты плагина запускаются из его каталога той же командой discovery.

### Что проверяется

- Синтаксис Lua 5.1, загрузка профиля и построение настроек, в том числе служебный TARGET.
- Угроза и цель индикатора выключены в значениях по умолчанию всех типов. Явно сохранённые пользовательские настройки не перезаписываются.
- Работа настоящего движка тегов oUF после удаления Private, очистка при скрытии/повторном использовании рамки; пул текстов ограничен пиковым числом одновременно созданных подписей, а не числом разных имён.
- Настройки собственных текстов сравнены с настоящей схемой юнит-фреймов: диапазоны, обводки, выравнивание, создание/удаление, смена профиля. Проверены реальные теги, [mouseover], таймер стороннего тега без событий, переиспользование и поднятый слой текста.
- Выключенные дополнительные элементы не создают текстов и не запрашивают данные; неизменные значения не переустанавливают шрифты, привязки и строки.
- Копирование обеих осей нативных привязок аур; независимые пользовательские привязки и возврат к клиентским значениям.
- Только клиентские источники лечения/поглощения, ограничение входящего лечения с учётом поглощения лечения. Пример: 90/100 HP, поглощение лечения 40, входящее лечение 30 не обрезается до 10.
- Реальные функции адаптера и юнит-фреймов в связке: щит при полном HP в NORMAL/STACKED/REVERSED, горизонтальная/вертикальная полоса, первое отображение без ожидания OnUpdate, событие щита без изменения здоровья, исчезновение/переполнение и отключение элемента.
- Alt-покупка и подтверждения, модификаторы, ремонт, выкуп; загрузка функциональности без скинов и без повторной установки обработчиков.
- PvP-привязки и центрирование текста, маркер захвата, поля диалогов, общие слои списка экипировки, оформление приглашения/талантов/ладдера, актуальная вкладка рейда.
- Иконка приглашения восстанавливает исходную текстуру, если предыдущий скин её очистил, и рисуется выше фона на слое ARTWORK.
- Английская и русская локали новых настроек, синхронность версии трёх компонентов и неизменность опубликованного changelog 9.09.07.

Общая модель рамок больше не принимает произвольные неизвестные Set*/Get* вызовы. Отдельная модель рендеринга юнит-фреймов также использует явный список API. Но заглушки не воспроизводят настоящий рендеринг, защищённое исполнение, taint и все тайминги клиента — эти проверки не заменяют игру и не измеряют FPS.

## Обязательная проверка в клиенте Sirus

- [ ] PvP-счётчик не дрожит, текст отцентрирован при разной длине; проверить бой, масштаб и PvPMover.
- [ ] У полосы захвата видны указатель, стрелки и нейтральный участок; крайние значения и смена направления работают.
- [ ] В заметке офицера текст и курсор не обрезаны; многострочные диалоги сохраняют высоту.
- [ ] Alt+ЛКМ/ПКМ покупает стак для поштучных товаров и упаковок, в том числе с отключёнными глобальными скинами/скином продавца. Проверить деньги, остаток, предметную валюту, честь/арену и подтверждения. Обычный клик, Shift/Ctrl, ремонт, курсор с предметом и выкуп не изменены.
- [ ] Щит появляется и исчезает на индикаторе, сумма не обрезается при поглощении больше максимума здоровья.
- [ ] На новом/сброшенном профиле угроза и цель выключены. При ручном включении обновляются и очищаются, в том числе при повторном использовании индикатора.
- [ ] Пользовательские `[name]`, `[curhp]`, `[maxhp]`, `[absorbs]`, `[incomingheals]` работают. Проверить смену профиля, типа индикатора, отключение, удаление и повторное создание текста.
- [ ] «Свой текст»: все обводки, размер, выравнивание LEFT/CENTER/RIGHT с автоматической привязкой, смещения ±400, Frame/Health/Name/CastBar. Проверить скрытый CastBar, [mouseover], сторонний тег без событий, старые ручные позиции и режим Automatic; подпись должна быть выше полос здоровья/каста.
- [ ] Бафы/дебафы/контроли по умолчанию следуют Sirus в classic/modern и при имени внутри/над полосой. Изменение привязки или смещения включает собственное положение; «Сбросить положение» возвращает нативное. Размеры и интервалы переключаются отдельно.
- [ ] Юнит-фреймы игрока/цели/группы/рейда показывают щит при полном и неполном здоровье. Проверить NORMAL/STACKED/REVERSED/NONE, обе ориентации, прозрачное здоровье, масштаб и появление щита без изменения HP.
- [ ] Входящее собственное/чужое лечение и поглощение лечения отображаются в согласованных сегментах; переполнение не оставляет старых полос. Сторонний аддон с LibHealComm не меняет источник данных ElvUI.
- [ ] Иконка ReturningPlayerInviteToggleButton видна; подсказка, нажатие и окно приглашений работают после повторного открытия списка друзей.
- [ ] Заголовки талантов затемнены полностью; подложки иконок категорий ладдера отсутствуют; кнопка RaidUtility открывает вкладку рейда.
- [ ] Список замены экипировки находится выше сокетов/зачарований и не закрывается при переходе между предметами, в том числе у запястий; направление остаётся клиентским для всех слотов.
- [ ] Плагин 1.16: исходящий/входящий урон, лечение, питомец, смена цели и повторное использование рамок. Чужой бой не отображается, цифры старой цели не переносятся на новую.

## Миграция и версия

Версия основных компонентов — 9.09.08. История уже опубликованной 9.09.07 сохранена без изменений. Загружается только тонкий адаптер oUF_SirusHealPrediction, читающий UnitGetIncomingHeals, UnitGetTotalAbsorbs и UnitGetTotalHealAbsorbs. Собственной базы заклинаний и обмена сообщениями нет. Имена HealCommBar/методов оставлены для совместимости. Старые файлы библиотеки — незагружаемые заглушки для обновления поверх старой установки.
