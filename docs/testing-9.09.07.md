# Проверка 9.09.07

## Автоматические проверки

Для локального запуска: Python 3, `pip install lupa`, затем `python tests/test_sirus_regressions.py`. Для интеграционных тестов плагина клонировать ElvUI_DmgAtNameplates рядом с ElvUI-for-Sirus; без него соответствующие тесты пропускаются.

Проверяются синтаксис Lua 5.1, полная загрузка профиля (включая служебный TARGET), построение настроек, создание/удаление текста, настоящий движок тегов oUF, очистка тегов при повторном использовании рамки, независимость привязок аур, отсутствие зависимости от LibHealComm, данные клиентского исцеления, переполнение и очистка полос, поглощение, угрозы и цель, PvP-привязки, маркер захвата, высота диалогов, расчёт покупки и интеграция плагина. Заглушки API не воспроизводят защищённое исполнение и визуальный рендеринг клиента.

## Обязательная проверка в клиенте Sirus

- [ ] На поле боя счётчик не дрожит при изменении очков и числа баз. Проверить вход/выход из боя и перемещение PvPMover.
- [ ] У полосы захвата видны указатель, стрелки и нейтральный участок; крайние значения, смена направления и масштаб интерфейса работают.
- [ ] В заметке офицера текст и курсор не обрезаны; многострочные диалоги не теряют высоту.
- [ ] Alt+ЛКМ/ПКМ у продавца покупает стак для поштучных товаров и упаковок. Проверить недостаток денег, остаток товара, честь/арену/предметную валюту, подтверждения дорогих покупок. Обычный клик, Shift/Ctrl, ремонт и выкуп не изменены.
- [ ] Щит появляется и исчезает на индикаторе, сумма не обрезана при поглощении больше максимума здоровья.
- [ ] Процент угрозы меняется у враждебного НИП, отсутствие угрозы не оставляет старую подпись.
- [ ] Цель индикатора обновляется и очищается при исчезновении цели.
- [ ] Тексты с `[name]`, `[curhp]`, `[maxhp]`, `[absorbs]`, `[incomingheals]` работают. Проверить смену профиля, отключение, удаление, скрытие и повторное использование индикатора.
- [ ] Бафы/дебафы/контроли по умолчанию следуют Sirus, в том числе classic/modern и имя внутри/над полосой. Отключение «Положение Sirus» позволяет отдельно менять привязку и смещения; «Размер и интервалы Sirus» управляет источником размеров.
- [ ] Полосы лечения и поглощения у игрока/цели/группы/рейда получают данные Sirus без LibHealComm. Проверить собственное/чужое лечение, поглощение лечения, ориентации и стили поглощения. Сторонний аддон с LibHealComm не должен менять источник данных ElvUI.
- [ ] Плагин 1.16: исходящий/входящий урон, лечение, питомец, соседний НИП, смена цели, скрытие и повторное использование рамок. Цифры старой цели не появляются на новой.

## Миграция библиотеки

Загружается только тонкий адаптер отображения oUF_SirusHealPrediction, который читает `UnitGetIncomingHeals`, `UnitGetTotalAbsorbs` и `UnitGetTotalHealAbsorbs`. Он не рассчитывает силу заклинаний и не отправляет сообщения аддона. Имена полей HealCommBar и методов юнит-фреймов оставлены для совместимости существующих настроек. Старые пути LibHealComm/oUF_HealComm4 содержат только незагружаемые пустые заглушки для обновления поверх старой установки; реализации библиотеки в них нет.
